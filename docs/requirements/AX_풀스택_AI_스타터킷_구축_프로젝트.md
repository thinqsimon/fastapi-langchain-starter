## 2차 프로젝트는?

FastAPI·React·PostgreSQL·LangChain 기반 AI 서비스를 CI/CD로 자동 배포되는 재사용 가능한 보일러플레이트로 구축하고, 누구든 Fork해 바로 시작할 수 있도록 문서화하는 프로젝트입니다.

## 📁 프로젝트 설명

이 프로젝트는 서비스 하나를 완성하는 데서 나아가, 다음 AI 서비스를 빠르게 시작할 수 있는 재사용 가능한 구조를 설계하고 코드 품질과 문서화까지 완성하는 풀스택 엔지니어링 역량을 기르는 프로젝트입니다.

각 팀은 FastAPI 백엔드, PostgreSQL 데이터베이스, React 프론트엔드, LangChain 기반 LLM 연동을 하나의 저장소로 묶어 스타터킷을 구성합니다. 인증, 데이터 모델, 에러 처리·로깅, LLM 연동 같은 공통 기반을 모듈화하고, GitHub Actions로 빌드·테스트·배포가 자동으로 이루어지도록 구성합니다. 마지막으로 스타터킷을 처음 접하는 사람이 문서만 보고 Fork해 실행·배포할 수 있는지 검증합니다.

## 🎯 프로젝트 목표

1. 재사용 가능한 AI 서비스 스타터킷의 범위와 구조를 설계합니다.
2. FastAPI·React·PostgreSQL·LangChain 기반의 공통 기반(인증, 데이터 모델, LLM 연동)을 모듈화하여 구현합니다.
3. GitHub Actions로 빌드·테스트·배포가 자동화되는 CI/CD 파이프라인을 구성합니다.
4. Fork만으로 새로운 AI 서비스를 시작할 수 있는 수준으로 코드 품질과 문서를 완성합니다.

## 🧭 프로젝트 로드맵

아래 4단계를 순서대로 완료하며, 설계부터 자동 배포, 재사용성 검증까지 스타터킷을 구축합니다.

1. **1단계 · 스타터킷 범위 및 구조 설계**
   스타터킷에 포함할 기능과 디렉터리 구조, 환경 설정 분리 기준을 정의합니다.
2. **2단계 · 백엔드·프론트엔드 공통 기반 구현**
   FastAPI 계층 구조, 데이터베이스 모델과 마이그레이션, 인증, React 기본 화면과 API 연동을 구현합니다.
3. **3단계 · LLM 연동 및 CI/CD 구성**
   LangChain 기반 LLM 연동 모듈을 구성하고, GitHub Actions로 빌드·테스트·배포 파이프라인을 구축합니다.
4. **4단계 · 재사용성 검증 및 문서화**
   Fork한 새 환경에서 문서만으로 실행·배포가 되는지 검증하고, 사용 가이드를 완성합니다.
