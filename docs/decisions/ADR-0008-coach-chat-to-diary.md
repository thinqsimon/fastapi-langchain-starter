# ADR-0008: 구름 코치 UI와 채팅에서 일기 초안 만들기

- 날짜: 2026-10-26
- 상태: 채택
- 기능: COACH-01 (사용자가 요청한 다음 단계로 DOC-02보다 우선)

## 결정

사용자가 제공한 구름 이미지를 `frontend/public/coach/cloud-coach.png`에 원본 그대로 두고
Next Image로 표시한다. 시작 화면, 추천 질문, 응답 아바타, 일기 만들기 버튼은
`applications/diary-coach/chat-experience.tsx`에 둔다. 공통 채팅은 프로필 조립 지점에서
선택된 헤더·빈 화면·응답 표시 정보만 받으며 starter에는 코치 UI를 노출하지 않는다.
공통 응답 본문은 기존 안전한 MarkdownView로 그린다.

채팅 버튼은 일기 화면의 이전 선택값과 관계없이 **클릭한 시점의 대화 ID**로 기존
`POST /api/diary/draft`를 호출한다. 성공하면 저장하지 않은 초안을 일기 편집 화면에 넘긴다.
날짜는 사용자 기기 기준이고 출처 ID·마지막 메시지 시각·날짜를 저장 요청까지 유지한다.
DB 스키마와 API 계약은 바꾸지 않는다. 서버의 409 재발행 제한도 그대로 적용한다.

## 상태와 오류

- 저장하지 않은 일기가 있으면 교체 확인 창을 먼저 보여준다. 취소하면 요청하지 않는다.
- 생성 중 버튼을 비활성화하고 스토어에서도 중복 요청·저장을 막는다.
- 저장 중 입력·취소를 잠가 이미 저장된 출처로 다시 생성 요청하는 경합을 막는다.
- 생성 실패 시 기존 입력은 유지하고 서버 오류를 표시한다. 자동 저장은 없다.
- 요청 시작 당시의 입력 revision과 계정 세대를 비교한다. 기다리는 동안 새로 쓴 입력이나
  로그아웃 뒤 상태를 늦은 응답으로 덮지 않는다. 초안은 메모리 상태이며 새로고침 시 사라진다.
- 공통 채팅도 로그인·로그아웃 시 초기화하고 이전 계정의 늦은 응답을 무시한다.
  다른 채팅에서 늦게 도착한 토큰·답변·실패는 현재 대화 상태를 바꾸지 않는다.
- 요청 후 채팅을 바꾸어도 초안의 출처는 클릭 당시 대화다. 채팅 화면을 떠났다면 강제로
  이동시키지 않으며 일기 메뉴에서 준비된 초안을 확인할 수 있다.

## 검증

기존 서비스·starter E2E에 더해 출처 보존, 수정 후 저장, 재발행 409, 미저장 교체,
실패·지연·로그아웃 경합, 모바일 폭을 검증한다. CI에서 데스크톱·모바일 화면을 보관해
실제 배치를 확인한다. 모든 테스트는 fake LLM을 사용한다.
