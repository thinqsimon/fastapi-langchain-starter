# ADR-0003 사용자·토큰 스키마

- 상태: 채택 (2026-10-15)

## 결정
| 항목 | 선택 | 이유 |
|---|---|---|
| users PK | UUID | 스타터킷이 외부 시스템과 합쳐질 때 충돌이 없고, ID로 가입자 규모가 드러나지 않는다 |
| 필드 범위 | email, password_hash, display_name, is_active + 타임스탬프 | 어떤 AI 서비스에도 공통인 것만. 약관 동의·권한 등은 Fork한 쪽에서 추가 |
| 비밀번호 | bcrypt 해시만 저장 | 평문·가역 암호화 금지 |
| 리프레시 토큰 | 별도 테이블에 SHA-256 해시로 저장 | 로그아웃·토큰 회전·탈취 대응이 가능하다. 무상태 JWT만 쓰면 로그아웃을 구현할 수 없다 |
| 사용자 삭제 | `is_active=false` (행 유지) | 대화 이력의 외래키가 깨지지 않는다 |
| 기본값 | Python + DB 양쪽(`server_default`) | ORM을 거치지 않는 시드·psql 작업에서도 INSERT가 성공해야 한다 |

## 대안
- 정수 auto-increment PK: 수업 예제와 같아 단순하지만 ID로 가입자 수가 노출된다
- 무상태 리프레시 토큰: 구현은 쉬우나 로그아웃·토큰 폐기가 불가능하다
